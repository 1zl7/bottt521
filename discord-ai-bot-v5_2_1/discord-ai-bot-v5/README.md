# 🤖 Discord AI Bot v5.2 (AgentRouter + claude-opus-5)

بوت يحل لعبة **الأعلام** (يعرف الدولة من صورة العلم)، ويكتب كلمات **اسرع**، ويسولف مع الناس بالـ AI.
نظام اللعبة الحين بنقطة: **`.اعلام`**

> ⚠️ اقرأ قسم «تنبيه مهم» تحت قبل التشغيل.

---

## 🚀 تشغيل سريع

```bash
# يحتاج Node 20 أو أحدث (يفضل 22). ما فيه مكتبات تنزّلها، ما تحتاج npm install
cp .env.example .env      # عدّل القيم
npm run dry               # تجربة: يحلل ويطبع بدون ما يرسل أي شي
npm start                 # تشغيل فعلي
```

### القيم المطلوبة في `.env`
| المتغير | من وين |
|---|---|
| `DISCORD_TOKEN` | توكن حسابك (أو توكن بوت، شوف تحت) |
| `CHANNEL_ID` | رابط القناة: `discord.com/channels/السيرفر/**القناة**` |
| `AGENTROUTER_API_KEY` | agentrouter.org/console/token (Create New Token) |
| `AI_MODEL` | الافتراضي `claude-opus-5`، لازم يكون ضمن «Model restrictions» في توكنك (أو اتركها فاضية هناك) |

> أي متغير ناقص يوقف البوت برسالة واضحة.

## 🎮 أمر اللعبة

الافتراضي `.اعلام` (بادئة `.` + اسم اللعبة `اعلام`).
- لو لعبتك تبي مسافة: ضع `GAME_START_COMMAND=. اعلام`
- غيّر البادئة: `GAME_PREFIX=!` أو الاسم: `GAME_NAME=اسرع`
- البوت يتعرف على أوامر الناس بكل الأشكال: `.اعلام` و `. اعلام` و `-اعلام` و `اعلام-`

## ⏱️ الفاصل بين الأعلام
`FLAG_GAP_SEC=15-20` (الافتراضي): بين كل إجابة علم والتالي لازم يمر 15 إلى 20 ثانية (يتغير عشوائي كل مرة). ملاحظة: لو بوت اللعبة له مهلة لكل علم أقصر من كده، ممكن الجولة تنتهي قبل ما يرد. اضبطه أو خليه `0` لو حبيت.

## 🕹️ تحكم من حسابك (من الجوال)
اكتب في القناة: `!bot pause` للإيقاف، `!bot resume` للتشغيل (يحط ⏸️ / ▶️ على رسالتك). الأمر يشتغل من حسابك أنت فقط.

## 🧠 الموديل (AgentRouter)
- الافتراضي: **`claude-opus-5`** للأعلام (يشوف الصور) وللدردشة بالمصري. سبب الاختيار: من الموديلات الأربعة اللي ظاهرة عندك هو الأضمن بالصور وبالعربي. `deepseek-v4-flash` ممكن يكون أسرع وأرخص بس ما أقدر أتأكد إنه يقبل صور، و`gpt-6-astra` ما أعرف عنه شي.
- الاتصال عبر `https://agentrouter.org/v1/chat/completions` (متوافق مع OpenAI).
- لو تبي احتياط: `VISION_MODELS=claude-opus-5,claude-opus-4-8` (وبنفس الطريقة `CHAT_MODELS`). لو الأول وقف أو خلصت حصته ينتقل للتالي.
- يتأكد عند التشغيل إن الموديل موجود عند المزود، ولو خلص الرصيد (402/403) يوقف الموديل 30 دقيقة ويكمل الدردشة بردود جاهزة بدون AI.
- لو الموديل رفض `temperature` يعيد الطلب بدونها لحاله. لو ما قدر يجيب رابط صورة ديسكورد ينزّلها ويرسلها base64 ويتذكر (أو ثبّتها بـ `IMAGE_AS_BASE64=true`).
- **التكلفة**: ما أعرف سعر `claude-opus-5` عندهم بالضبط، فراقب الاستهلاك في لوحة AgentRouter أول ساعة. الدردشة بالـ AI شغالة، ومعاها سقف `AI_CHAT_PER_HOUR=120` (الافتراضي): بعده يكمل يسولف بردود جاهزة والرصيد يبقى للأعلام. ارفعه أو خليه `0` لو تبي دردشة بالـ AI بلا حد.
- **ما جربته على AgentRouter الحقيقي** (ما عندي وصول لمفتاحك ولا شبكة). الاختبارات على سيرفر وهمي. ولو رفض الطلبات برسالة مثل `unauthorized client` فهذا قيد من عندهم على الأدوات المسموحة، وما راح أحاول أتجاوزه بالكود.

## ☁️ وين تستضيف

البوت يدور 24/7 (فحص القناة كل ثانية تقريباً)، فتحتاج مكان ما ينام. حسب المقالات اللي قرأتها (تأكد من صفحات الأسعار لأنها تتغير):

| الخيار | ملاحظة |
|---|---|
| **كمبيوترك / راسبيري باي** | أبسط وأضمن، وأقل شي يخوّف ديسكورد. يوقف لو طفيت الجهاز |
| **Oracle Cloud Always Free** | سيرفر مجاني فعلاً ويشتغل دايم، لكن التسجيل متعب ولازم تدير لينكس بنفسك |
| **VPS رخيص** (Hetzner وأمثاله) | عادة بضع دولارات بالشهر، أنصح فيه لو تبي شي مستقر |
| Railway | ما فيه خطة مجانية دائمة (رصيد تجريبي فقط) |
| Render | الخطة المجانية تنام بعد 15 دقيقة، والـ workers مو مجانية → ما تنفع |
| Fly.io | ما فيه مجاني للحسابات الجديدة |

### تشغيله على VPS (أوبونتو)
```bash
sudo apt update && sudo apt install -y nodejs npm git   # أو ثبّت Node 22 من nodesource
# ارفع المجلد (scp أو git)، ثم:
cd discord-ai-bot && cp .env.example .env && nano .env
sudo npm i -g pm2
pm2 start index.js --name flagbot
pm2 save && pm2 startup      # ينفذ الأمر اللي يطلعه لك عشان يشتغل بعد إعادة التشغيل
pm2 logs flagbot             # تشوف اللي يصير
```

### على Railway (لو عندك رصيد)
1. ارفع المشروع على GitHub (ملف `.env` ما يترفع، موجود في `.gitignore`)
2. New Project → Deploy from GitHub
3. Variables: `DISCORD_TOKEN` و `CHANNEL_ID` و `AGENTROUTER_API_KEY`
4. أمر التشغيل `npm start` (ما تحتاج PORT)

لو الاستضافة تطلب بورت: ضع `PORT=3000` وراح يفتح `/health` و `/stats`.

## ⚠️ تنبيه مهم (اقرأه)

**استخدام توكن حسابك الشخصي (self-bot) يخالف شروط ديسكورد وممكن ينحظر الحساب.** هذا الخطر موجود بالنسخة القديمة والجديدة، وما أقدر أشيله من الكود. تقليل الضرر:
- استخدم **حساب ثانوي** مو حسابك الأساسي.
- جرّب `npm run dry` أول.
- ديسكورد أحياناً يشك في الدخول من سيرفرات الاستضافة (ما أقدر أأكد لك متى)، فالحساب الثانوي أهم لو تستضيف على VPS.
- بديل نظيف للجزء الاجتماعي: سوّ **بوت رسمي** من discord.com/developers وحط `DISCORD_TOKEN_TYPE=bot`. (لازم تفعّل Message Content Intent، وبوت اللعبة ممكن يتجاهل رسائل البوتات، فحل الأعلام قد ما يشتغل بهالطريقة.)

خطوات استخراج التوكن بالـ F12 اللي كانت في README القديم شلتها: لا تشاركها ولا ترفع توكنك لأي مكان، ولو تسرّب غيّر الباسورد فوراً.

الدردشة: مصممة تتجاهل أي تعليمات من الناس، وتحذف الروابط والمنشن (@everyone) من ردودها، وفيها قاطع طوارئ (`MAX_SENDS_PER_MIN`, الافتراضي 40) يمنع حلقات الرد بين بوتين.

## 🔧 مشاكل شائعة
| المشكلة | الحل |
|---|---|
| `التوكن غلط أو منتهي` | جدّد التوكن، أو جدّد مفتاح AgentRouter |
| ما يرد على الأعلام | شوف السجل: `Vision خطأ`. غالباً اسم الموديل مو ضمن توكنك → عدّل `AI_MODEL` أو قيود الموديلات في التوكن |
